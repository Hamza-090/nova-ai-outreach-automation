# n8n Workflow

This directory contains the sanitized n8n workflow used by the
AI Lead Outreach Automation project.

The workflow includes:

- LinkedIn lead discovery
- Lead filtering
- Email enrichment
- AI email generation
- Gmail draft creation
- Google Sheets tracking
- Human review
- Edit / Send / Cancel actions
- Webhook-based frontend integration

API credentials and secrets have been removed from the exported workflow.
